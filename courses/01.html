Section 1.1: Hello World

A simple "Hello World" example to get started with HTML5.

HTML Example
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hello World</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>Welcome to HTML5.</p>
</body>
</html>

This basic HTML structure includes:

  • HTML5 doctype declaration
  • Character encoding meta tag
  • Viewport meta tag for responsive design
  • Page title
  • Heading and paragraph elements

Section 2.1: Adding the Doctype

The doctype declaration tells the browser which version of HTML the page is written in.

HTML5 Doctype
<!DOCTYPE html>

Key points about doctypes:

  • Must be the very first thing in your HTML document
  • HTML5 doctype is simple and backwards compatible
  • Helps browsers render pages correctly
  • Triggers standards mode in browsers

Section 5.1: Text Highlighting

HTML5 provides semantic elements for text formatting.

Highlighting Text
<p>This is <mark>important text</mark> that should be highlighted.</p>
Result

This is important text that should be highlighted.

The <mark> element represents text that is marked or highlighted for reference purposes, due to its relevance in another context.
