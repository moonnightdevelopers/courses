Section 1.1: Hello World Example

This example demonstrates the basic structure of an HTML5 document with a simple "Hello World" message.

HTML Code 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hello World</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>Welcome to HTML5 programming.</p>
</body>
</html>
Section 1.2: Basic HTML Structure

Understanding the basic structure of an HTML document is fundamental.

Basic Structure 
<!DOCTYPE html>
<html>
    <head>
        <!-- Metadata goes here -->
        <title>Page Title</title>
    </head>
    <body>
        <!-- Content goes here -->
        <header>Header Content</header>
        <main>Main Content</main>
        <footer>Footer Content</footer>
    </body>
</html>
Section 17.1: Text Input Elements

Text input fields are the most common form elements in HTML.

Text Input Examples 
<!-- Simple text input -->
<input type="text" id="username" name="username" 
       placeholder="Enter your username">

<!-- Password field -->
<input type="password" id="password" name="password" 
       placeholder="Enter your password">

<!-- Email field with validation -->
<input type="email" id="email" name="email" 
       placeholder="email@example.com" required>

<!-- Textarea for multi-line input -->
<textarea id="message" name="message" 
          rows="4" cols="50" 
          placeholder="Enter your message here">
</textarea>
