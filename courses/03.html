Getting Started

HTML (Hypertext Markup Language) uses a markup system composed of elements which represent specific content. Markup means that with HTML you declare what is presented to a viewer, not how it is presented.

<!DOCTYPE html>
<html lang="en">
<head>
  <title>My First HTML Page</title>
</head>
<body>
  <h1>Hello World!</h1>
</body>
</html>

HTML5 Doctype Declaration

The HTML5 doctype declaration is very simple and easy to remember. It must be the very first thing in your HTML document, before the <html> tag.

<!DOCTYPE html>
<html>
  <!-- Your content here -->
</html>

Creating Hyperlinks

Links are specified in HTML using the <a> (anchor) element. The href attribute specifies the destination of the link.

<!-- External link -->
<a href="https://www.example.com">Visit Example.com</a>

<!-- Internal link -->
<a href="#section1">Go to Section 1</a>

<!-- Email link -->
<a href="mailto:someone@example.com">Send Email</a>
